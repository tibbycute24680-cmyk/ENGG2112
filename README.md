The file preview may not show up in Github, and show an error. This is a Github rendering issue. You can just download the file and open it up in an IDE and then you will be able to see the code.
The files in the data engineering branch (titled data-engineer-branch-(code-for-data-but-not-used-in-actual-model)) should be run first. This is the pre-processing section before training the model. 
weather_data_code.ipynb imports, cleans, and formats the weather data. merge_flight_data_code.ipynb reads the flight data from where you saved it, then cleans and formats it before exporting the usable dataset. merge_egse_data.ipynb cleans and formats the eGSE demand data before exporting it. Once you have the three cleaned datasets, use merge_final.ipynb to merge the cleaned datasets. Use check_final_dataset.ipynb to ensure everything looks correct with the data in the final merged dataset. Here, use split_data.ipynb to split into test, train, and validation datasets. Then use features.ipynb on the seperated datasets to add the features. The code was designed to do these with one set of yearly data, so you must re-run this pipeline of pre-processing for each year of data you have. 
Then, in the main branch, use the xgboost_code.ipynb to see the training and tuning of the model, as well as evaluation metrics and figures. The additional files in both the main branch and the data engineering branch were involved in developing code for the model but are not part of the final pipeline.
